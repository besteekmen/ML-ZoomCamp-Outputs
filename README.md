## 🎯 What I'm Learning & Building

Throughout this cohort, I am building hands-on experience with:

- **Machine Learning Fundamentals:** Understanding the ML workflow, problem formulation, and working with real-world datasets.
- **Regression & Classification:** Building and training predictive models using scikit-learn.
- **Feature Engineering:** Preparing data, encoding categorical variables, selecting features, and improving model performance.
- **Model Evaluation:** Using appropriate metrics and validation techniques to evaluate machine learning models.
- **Tree-Based Models:** Working with decision trees, random forests, gradient boosting, and XGBoost.
- **Deep Learning:** Building neural networks and deep learning models using PyTorch and TensorFlow/Keras.
- **Model Deployment:** Turning trained models into production-ready services using FastAPI and Docker.
- **Cloud & Serverless ML:** Deploying machine learning models to cloud and serverless environments.
- **Scalable Model Serving:** Learning how to deploy and serve models using Kubernetes and model-serving technologies.
- **End-to-End ML Engineering:** Taking a machine learning project from data preparation and training to deployment and serving.
